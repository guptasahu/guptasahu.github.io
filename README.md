# Gupta Sahu Portfolio

A responsive, accessible one-page portfolio built with plain HTML, CSS and JavaScript for deployment on GitHub Pages.

## Files
- `index.html`: page content and structure
- `styles.css`: responsive visual design
- `script.js`: mobile navigation and dynamic footer year

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish
Create a GitHub repository, upload these files to its root, then open **Settings > Pages**. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Privacy note
The public site intentionally omits the phone number from the resume to reduce spam and unwanted calls. Add it to the Contact section only if you want it publicly searchable.
